# OpenCode-Verbindung

Wenn PiChamber lädt, aber nie über „OpenCode is restarting“ hinauskommt, oder der Chat nicht antwortet, ist der Server, mit dem es spricht, nicht erreichbar. Gehen Sie diese Punkte durch.

## Es hängt bei „OpenCode is restarting“

- geben Sie ihm direkt nach dem Start einen Moment — dieser Zustand ist normal, während der Server hochfährt
- prüfen Sie mit `pichamber status`, ob der Server noch läuft
- starten Sie ihn mit `pichamber restart` neu
- sehen Sie sich mit `pichamber logs` die Startdetails an

## Sie verbinden sich mit Ihrem eigenen Server

Wenn Sie PiChamber so konfiguriert haben, dass es einen vorhandenen Server nutzt, prüfen Sie die Einrichtung aus [OpenCode Server](/opencode-server/) noch einmal:

- `OPENCODE_HOST` muss den Port enthalten, aber keinen Pfad — zum Beispiel `http://localhost:4096`
- setzen Sie `OPENCODE_SKIP_START=true`, damit PiChamber nicht auch noch seinen eigenen Server startet
- wenn die Adresse ungültig ist, ignoriert PiChamber sie und startet stattdessen seinen eigenen Server — achten Sie in den Logs auf eine `[config]`-Warnung

## Es schlägt immer noch fehl

- bestätigen Sie, dass Node.js Version `20` oder neuer ist
- installieren Sie die neueste CLI neu
- öffnen Sie `http://localhost:3000` direkt, bevor Sie einen Tunnel- oder Remote-Link testen
