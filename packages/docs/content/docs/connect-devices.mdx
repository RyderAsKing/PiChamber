---
title: Connect devices
description: Pair a trusted device with an existing PiChamber server.
---

On the server, create a one-time pairing link:

```sh
pichamber connect-url --qr
```

Open or scan the link from the device you want to connect. Pairing grants that device access to the server's workspace, so use it only for devices you control. Revoke access from the server when a device is no longer trusted.

Remote PiChamber clients operate on the server's filesystem and use the server's Pi configuration and credentials.
