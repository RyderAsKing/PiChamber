---
title: PiChamber
description: Run and supervise Pi Coding Agent sessions from a browser or desktop app.
---

PiChamber is a self-hosted workspace for Pi Coding Agent. A PiChamber server owns a private Pi session daemon, exposes authenticated browser APIs, and lets trusted devices work with the same sessions.

PiChamber uses the Pi SDK directly. It does not require an independently installed Pi CLI or a separately running Pi server.
