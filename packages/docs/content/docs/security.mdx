---
title: Security
description: Understand PiChamber's single-owner security model.
---

A PiChamber server is a single-owner workspace server. Anyone you pair or otherwise authenticate can act on its sessions and server filesystem.

Keep public access disabled unless you have configured a UI password and a trusted network or reverse-proxy boundary. Do not share pairing links or server tokens. PiChamber never returns stored provider credentials to browser clients.
