---
title: Troubleshooting
description: Diagnose PiChamber server and session-daemon availability.
---

Check the server state:

```sh
pichamber status
pichamber logs
```

If the browser reports that Pi is unavailable, verify that the server host can read its Pi agent directory and that the server process has permission to create its local daemon socket. A daemon failure is reported explicitly; it is not an empty session list.

Stop and restart the host if the daemon cannot recover:

```sh
pichamber stop
pichamber serve --ui-password "choose-a-strong-password"
```
