---
title: Quick start
description: Start an authenticated PiChamber server and open its browser UI.
---

Start a local server:

```sh
pichamber serve --ui-password "choose-a-strong-password"
```

Open the reported local URL in a browser. The first request starts the private Pi session daemon; PiChamber then loads your normal Pi agent configuration and sessions.

Use `--lan` only on a trusted network and always set `--ui-password` when exposing the server beyond localhost.
