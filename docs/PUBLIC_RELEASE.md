## Reddit or Hacker News

**Title:** PiChamber [VERSION], a self-hosted desktop and web workspace for Pi Coding Agent

**Body:**

PiChamber is an open-source workspace around Pi Coding Agent. It began as a
community fork of OpenChamber and has since been substantially rewritten around
the Pi SDK. It runs Pi from a desktop app or a self-hosted server, then lets
trusted browser and mobile clients connect to the same sessions.

Pi owns sessions, providers, prompts, skills, extensions, and the session daemon.
PiChamber owns the workspace UI, authentication, device connections, and native
shells. The desktop backend runs in-process, and server installs use the
`@pi-chamber/web` package.

Downloads, install instructions, screenshots, and the source are here:
[RELEASE_URL]

Feedback on operating systems, remote access, extensions, and the contribution
workflow is useful. Please report security issues privately as described in
`SECURITY.md`.
